# Imagens do Link de Estoque

Fotos de produto usadas pelo link de estoque das franquias, servidas pela
CDN jsDelivr:

    https://cdn.jsdelivr.net/gh/FelipeIttner930/imagens_estoque@main/miniatura/{ref}_{cor}.webp
    https://cdn.jsdelivr.net/gh/FelipeIttner930/imagens_estoque@main/grande/{ref}_{cor}.webp

- `miniatura/`: até 300 px (vitrine)
- `grande/`: até 800 px (detalhe do produto e envio ao cliente)

Não suba fotos direto aqui: gere com `fotos.converter` do projeto
estoque_franquias, que padroniza formato, tamanho e nome.
